# Changelog

All notable changes to this project will be documented in this file.

## 2026.11.19

### Changed
- Breaking: the package is now used through the `mux()` and `demux()` functions (see `README.md`). The `CSSCANMuxBus` and `CSSCANMuxReader` classes, the `csscan_mux` python-can interface and the command-line tool support are removed.
